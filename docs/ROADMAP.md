# Roadmap — posisi v1.7.0

| Bagian | Source | Gerbang yang belum terbukti |
|---|---|---|
| Website/demo/katalog | Ada | Build dan browser asli dengan dependensi proyek |
| Akun dan Supabase | Ada | Auth/SMTP/reset, SQL, pemisahan akun |
| Editor/autosave/foto | Ada | Runtime React dan Storage, konflik/offline dua tab |
| Pesanan/verifikasi/publikasi | Ada | Alur live staging, validasi mutasi bank oleh pengelola |
| Tamu/RSVP/moderasi | Ada | Token/consent/konkurensi dan grant server-only live |
| CMS/admin | Ada | Publish/harga/pesanan lama di database nyata |
| Tahap7 keamanan/gerbangrilis | Source baru dan unit/static tests | Lock/install/build, browser asli, SQLengine, staging, beban, backup/restore |

**Tujuh tahap source tidak berarti tujuh gerbang produksi sudah lulus.** Jangan lanjut menjual fitur yang belum diuji. Tahap7 memperkecil celah gateway, menambah alatbukti, dan tetap tidak mengesahkan produksi. Pekerjaan berikutnya memprioritaskan gerbang yang gagal, bukan menambah klaimfitur.

Backlog terpisah: musik, hadiah, gateway/refundotomatis, QRcheck-in, paketkuota, desainbaru, CAPTCHA/proteksimenyeluruh, Storagequota/cleanup, hapusakun/retensiotomatis, auditindependen, dan ujibeban.
